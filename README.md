# project-
Campus Lost & Found Management System

Project Description

The Campus Lost & Found Management System is a software application designed to help university students report and find lost belongings on campus.

Students often lose personal items such as mobile phones, wallets, books, watches, ID cards, and bags. This system allows students to report lost items and enables other students to report items they have found.

The system compares lost and found item records based on details such as item name, category, and location. It then displays possible matching items to help students identify and recover their belongings.

Main Features

* Report Lost Items
* Report Found Items
* View All Lost Items
* View All Found Items
* Search Items
* Find Possible Matching Items
* Delete Item Records

Project Objective

The main objective of this project is to provide a simple and organized platform that makes it easier for university students to report, search for, and recover their lost belongings.
